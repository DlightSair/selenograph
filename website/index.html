Selenograph

Selenograph

Lunar image registration · SIH 2026 · PS 26166

Co-registration of Chandrayaan-2 OHRC (0.25 m), TMC-2 (5 m) and IIRS (100 m) images to LRO reference mosaics. Runs that fail the fit checks are reported as No fit.

Source and reference differ in illumination, viewing geometry and scale. Each run matches tiles from coarse to fine, fits a transform, and checks it against held-out tiles before reporting an error.

01 · Features
Projects

One project per area: source product, reference mosaic, AOI.

Open it for images, last run and run history.

Registration

Normalized cross-correlation on image tiles, coarse to fine, starting from the product's control grid.

Homography fitted with MAGSAC.

Illumination

DEM re-lit at the source Sun angle.

Image representation (intensity, edges, cfog) selected per scene.

Viewing geometry

Cross-validated non-rigid residual field.

DEM parallax term for off-nadir views.

Fit checks

Held-out RMSE, scale and prior agreement, anchor count.

A run that fails is reported as No fit.

Local

Runs on your machine. No upload, no account.

Results are written next to the project.

02 · How it works
Crop to the AOIThe source strip is cut to the area of interest using its control grid. Large strips are block-averaged to about the reference resolution.
PriorThe control grid gives a starting guess for where the strip sits on the reference. It can be kilometres off.
CaptureSeveral image representations are tried on the same tiles. The one on which most tiles agree on one shift is kept.
RefineCoarse to fine: tiles are matched at higher resolution and a homography is refitted with MAGSAC at each stage.
Non-rigid and parallaxA smooth residual field and a DEM parallax term are added only if cross-validation shows they predict held-out tiles better.
Checks and outputScale, anchor count and prior agreement are checked. A passing run writes a georeferenced GeoTIFF and tie points. Otherwise: No fit.

First start

The first launch takes about 20 seconds while the built-in registration service starts. It runs hidden on its own private port, uses nothing installed on your machine, and stops when you close the app.

Projects and results are stored in %LOCALAPPDATA%\Selenograph.

04 · Data

The app does not ship imagery. A project needs a source product and a reference mosaic, downloaded separately.

Source: Chandrayaan-2

OHRC, TMC-2 and IIRS products (PDS4) from ISSDC PRADAN. Download the product folder, including its geometry folder.

PRADAN: Chandrayaan-2 payload data ↗

An ISSDC PRADAN account is required.

Reference: LRO

LROC NAC and WAC mosaics. Any georeferenced GeoTIFF works as a reference.

LROC QuickMap ↗ NASA Moon Trek (WAC global, NAC polar mosaics) ↗ LROC archive (RDR products) ↗
Elevation (optional)

A DEM enables the re-lit layer and the parallax term.

LOLA global DEM, 118 m (GeoTIFF) ↗ LOLA south polar DEM, 20 m (GeoTIFF) ↗
05 · Help
New project

File ▸ New project. Pick the source folder, then Fill from source to take the AOI from the product footprint. Set the reference GeoTIFF.

Run

Open a project and press Run. The banner shows the stage and elapsed time.

No fit

Source has no contrast, or too little overlap with the reference. The run page lists what was tried.

Reading the result

RMSE is the residual of inlier matches. Held-out RMSE is the error on tiles not used for the fit. There is no ground truth for real pairs.
